# Reporting Issues & Feedback

Rook is open source under the [MIT License](LICENSE). Its source repository is
[bringfire/Rook](https://github.com/bringfire/Rook); this repository carries the
docs, plugin metadata, and release assets. Your reports, questions, and ideas
genuinely shape where Rook goes, and we'd love to hear them.

## How to reach us

- **Report a bug** — open an issue in the source repository:
  [bringfire/Rook/issues](https://github.com/bringfire/Rook/issues), describing
  what you did, what you expected, and what actually happened.
- **Request a feature** — open an issue there describing the outcome you want.
- **Ask a question** — use [Discussions](https://github.com/bringfire/Rook/discussions),
  or email **bringfiregames@gmail.com**.
- **Report a security vulnerability** — see [SECURITY.md](SECURITY.md). Please do
  **not** open a public issue for security reports.

## A good bug report includes

- Your OS and **Rhino version**
- The AI client you're using (Claude Code, Codex, Cursor, …)
- What you asked Rook to do, and what happened
- Any error messages, and whether the connection checks pass
  (see [Set Up & Verify](https://bringfire.github.io/rook-release/start/setup-verify/))

## Pull requests

Code changes are accepted **by invitation**: a pull request to
[bringfire/Rook](https://github.com/bringfire/Rook) is taken only for an issue a
maintainer has marked `accepted` or `help wanted`, and unsolicited pull requests
are closed with a pointer to that rule. See the source repository's
[CONTRIBUTING](https://github.com/bringfire/Rook/blob/main/CONTRIBUTING.md) for
the full policy and the build and test workflow. MIT means you never need
permission to fork, modify or redistribute Rook.

This repository accepts pull requests for its docs and site under the same rule:
open an issue first.
