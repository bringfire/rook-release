A showcase of real work done *with* Rook — not instead of the designer. The point
is what becomes possible when the setup and busywork get out of the way.

:::tip[This is where Rook shows its value]
Rook can capture its own screens and views, so this page can be filled with real
captures of files Rook helped organize, lay out, or set up. The longer-term plan
is an interactive viewer so visitors can explore a model in the browser.
:::
